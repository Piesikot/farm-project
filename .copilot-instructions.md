## HTML Validation Requirements
- `<ul><li><a>` structure for `.topbar__menu` (currently: `<ul class="menu"><a>` — needs fixing)
- Menu items must be `<li class="topbar__menu__item"><a class="topbar__menu__button">...</a></li>`
- No inline `<style>` blocks (except alert in index.html)
- All class names lowercase with `__` and `--` separators only
